# Enterprise Insight Agent

企業の競争情報や意思決定を支援する、証拠に基づくリサーチ Agent です。研究計画、ウェブ検索、証拠評価、重要な主張の確認、引用の検証、追跡可能なレポートを一つのワークフローにまとめています。

本プロジェクトは [GPT Researcher](https://github.com/assafelovic/gpt-researcher) の研究・執筆基盤を引き継いでいます。ライセンスと出典については [LICENSE](LICENSE) をご覧ください。
