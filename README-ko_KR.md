# Enterprise Insight Agent

기업 경쟁 정보와 의사결정을 지원하는 증거 기반 리서치 Agent입니다. 연구 계획, 웹 검색, 증거 평가, 핵심 주장 검토, 인용 확인, 추적 가능한 보고서를 하나의 흐름으로 제공합니다.

이 프로젝트는 [GPT Researcher](https://github.com/assafelovic/gpt-researcher)의 연구 및 작성 기반을 계승합니다. 라이선스와 출처 정보는 [LICENSE](LICENSE)를 확인하세요.
